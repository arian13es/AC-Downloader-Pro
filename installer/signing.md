# راهنمای Code Signing — رفع قطعی Smart App Control / SmartScreen

## واقعیت فنی (بدون تعارف)

**Smart App Control** ویندوز ۱۱ و **SmartScreen** بر اساس دو چیز تصمیم می‌گیرند:
1. آیا فایل با **گواهی دیجیتال معتبر** امضا شده؟
2. آیا این امضا/فایل **شهرت ابری (reputation)** نزد مایکروسافت دارد؟

هیچ تغییر فنی در کد یا تنظیمات نصب‌ساز نمی‌تواند exe امضانشده را از SAC عبور دهد.
تنها راه‌حل واقعی برای انتشار عمومی: **امضای کد (Code Signing)**.

## گزینه‌های گرفتن گواهی (ارزان → گران)

| گزینه | قیمت | نکته |
|---|---|---|
| **Certum Open Source Code** | ~۲۵€/سال | ارزان‌ترین؛ مخصوص توسعه‌دهندگان اوپن‌سورس؛ اعتبار SmartScreen طی چند هفته ساخته می‌شود |
| **SignPath Foundation** | رایگان | برای پروژه‌های اوپن‌سورس فعال با اکانت GitHub — درخواست بده (signpath.org/foundation) |
| **Azure Trusted Signing** | ~۱۰$/ماه | سرویس رسمی مایکروسافت؛ سریع‌ترین راه گرفتن reputation؛ نیازمند احراز هویت مالی |
| گواهی OV (Sectigo/SSL.com) | ~۸۰-۱۵۰$/سال | استاندارد |
| گواهی EV | ~۲۵۰$/سال | اعتبار SmartScreen **فوری** (توکن سخت‌افزاری) |

## گزارش false positive (مکمل ضروری)

اگر هر آنتی‌ویروسی فایل را فلگ کرد، همین لینک گزارش بفرست — طی چند روز شهرت می‌سازد:
https://www.microsoft.com/en-us/wdsi/filesubmission

## امضای خودکار در این پروژه

`build.bat` به‌صورت خودکار امضا می‌کند اگر این دو متغیر محیطی ست شده باشند:

```bat
set SIGN_PFX=C:\path\to\mycert.pfx
set SIGN_PFX_PASS=********
build.bat
```

نیازمند `signtool.exe` (با نصب Windows SDK روی سیستم موجود می‌شود).
هر دو فایل `AC-Downloader.exe` و `AC-Downloader-Setup-*-win64.exe` با
SHA256 + timestamp امضا می‌شوند.

## توزیع

- منتشر کردن فقط از طریق **GitHub Releases** (دامنه معتبر = Mark-of-the-Web کم‌خطرتر)
- در متن Release بنویس: اگر ویندوز هشدار داد، روی فایل راست‌کلیک ← Properties ←
  تیک **Unblock** — و بعد از امضا، این هشدار کلاً حذف می‌شود.

## هشدار درباره گواهی Self-Signed (sign.bat)

اسکریپت `sign.bat` یک گواهی Self-Signed می‌سازد و در Trusted Root **همین سیستم** نصب می‌کند:
- ✅ مناسب برای تست محلی و حذف هشدار روی سیستم خودت
- ❌ روی سیستم کاربران دیگر **هیچ اثری ندارد** (آن‌ها به گواهی تو اعتماد نمی‌کنند)
- ❌ فایل `.pfx` تولیدشده را **هرگز** منتشر یا commit نکنید — امضای جعلی به نام شماست
- Smart App Control حتی با Self-Signed هم بلاک می‌کند (SAC فقط امضای شناخته‌شده ابری را قبول می‌کند)

برای انتشار عمومی: فقط گواهی واقعی (Certum / SignPath / Azure Trusted Signing).
